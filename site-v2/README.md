# Douglas D'Avila Portfolio v2

The Astro portfolio contains the migrated Lab and uses Supabase for Google login, owner approval, and shared execution allowances. GitHub Pages publishes the static build after backend deployment and browser acceptance tests pass.

## Local development

```sh
npm install
npm run dev
```

## Production verification

```sh
npm run build
npm run test:e2e
```

The static output is generated in `dist/`.

## Content

- `src/content/experience/` — career history
- `src/content/projects/` — case studies and experiments
- `src/content/writing/` — LinkedIn articles
- `src/data/site.ts` — contact, navigation, and profile links

The visual system is documented in the repository root `DESIGN.md`, with machine-readable extensions in `.impeccable/design.json`.

## Lab

- `/lab/user-story-analyzer`: existing deterministic INVEST review, metered by the backend.
- `/lab/context-graph`: reusable graph adapter/traversal/context/actions and the Gemini assistant.
- `/lab/context-graph/entity?entity=…`: linked entity records in the same interface.
- `/lab/neural-test-signal-classifier`: original illustrative scoring formulas, free to explore.
- `/settings`: owner-only approvals, limits, timezone, pause, notification recipient and history.

The default allowance is ten lifetime executions per user and ten daily across the whole site, including the administrator. Local simulations do not consume quota. Protected tools require approval; public project descriptions remain available. Static HTML and browser code are public by design; authorization, private user state and execution are enforced by Supabase.

`content/auth.runtime.json` at repository root supplies only this project's public anon key and URL to the build. Runtime files are ignored by Git and generated by CI. Never put a service-role key in them.

See [backend deployment](../docs/lab-backend-deployment.md) for the applied schema, email setup and live checks. Browser tests use mocked identities and API replies against the production build; they never create real recruiter accounts or send email.

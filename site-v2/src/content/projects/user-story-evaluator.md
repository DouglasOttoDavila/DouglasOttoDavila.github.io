## The quality problem

Ambiguous requirements create expensive disagreement downstream. The analyzer turns a user story into a structured review that highlights what is clear, what is missing, and what needs human discussion before implementation.

## What the system demonstrates

- Criteria-based review rather than a single opaque score.
- Suggested improvements tied to the original requirement.
- A human-review step before generated recommendations become delivery decisions.

## Current status

The Lab contains a protected demonstration using deterministic INVEST scoring and configurable review templates. Google sign-in and owner approval provide access within a shared execution allowance.

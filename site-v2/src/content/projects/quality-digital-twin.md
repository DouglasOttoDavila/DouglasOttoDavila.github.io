## A reproducible evidence world

Meridian Industrial Supply is entirely fictional. This experiment models release changes, explicit relationships and evidence across payment authorization, catalog accessibility and partner credit retries.

## Inspect before concluding

Replay immutable synthetic events, inspect directed claim trails, compare local forks and export a versioned JSON snapshot. Test coverage is separate from execution; code review is separate from release sign-off.

## AI with boundaries

Public replay contains authored interpretations. Optional live analysis uses server-side authentication and the shared Lab allowance. Model commentary never edits evidence or decides release readiness.

## The quality problem

AI recommendations become unreliable when delivery context is scattered across requirements, tests, systems, and ownership boundaries.

## The experiment

The graph lets a visitor traverse relationships and assemble relevant context before asking an assistant for analysis. It explores a practical question: what should an AI quality system know before it recommends an action?

## Current status

The interactive graph, entity details, and assistant workflow are available as a portfolio prototype.

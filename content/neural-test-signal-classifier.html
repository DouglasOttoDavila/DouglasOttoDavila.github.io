Project blueprint

What the implemented Python project should include

Dataset and features

Start with synthetic CI history, then support real imports from JUnit XML or CI CSV files. Key signals include retry behavior, flip rate, duration ratio, changed files, and error keywords.

Model comparison

Train logistic regression, random forest, and a small MLP. Keep the neural network honest by comparing macro F1, confusion matrix behavior, and class-level precision/recall.

Real-time visualization

Use Dash with dash-cytoscape to render input, hidden, and output nodes while replaying failures. Node intensity maps to activation, and output labels show live probabilities.

SDET delivery quality

Ship a CLI, prediction contract tests, feature extraction tests, activation-trace tests, and a compact evaluation report that explains where the model helps and where it should not be trusted.

Recommended stack

Best library choice for the real project

Dash plus dash-cytoscape is the strongest option for this project because it keeps the dashboard in Python while providing a real network canvas with callbacks, styling, zoom, drag, and click interaction.

Primary: Dash, dash-cytoscape, Plotly, NetworkX
ML: pandas, scikit-learn MLPClassifier, joblib
Quality: pytest, synthetic-data fixtures, activation-trace tests
Optional: FastAPI for CI integration, Streamlit for a simpler report-style dashboard

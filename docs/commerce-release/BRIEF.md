## Scope committed before implementation

- Flagship route and Lab entry; existing experiments retained.
- Requirement, Change, Impact, Tests, Diagnose, Verify.
- Executable browser checkout; baseline/patched versions; partial/full/declined/custom authorization; reversible prepared patch.
- Canonical twin artifacts and directed evidence paths, without rewriting twin history.
- Actual browser execution results and expected/actual evidence; mandatory test gates, budget selection, omitted-check residuals.
- Guided workflow, autoplay/pause/back/next/restart/take-control, snapshot restoration and contextual explanations.
- Source inspector, authored guidance, explicit authenticated NVIDIA analysis for five SDLC tasks; validated citations and visible stale analysis.
- Local review policy, acknowledgment, Markdown/JSON evidence exports.
- Responsive Terminal/Studio, keyboard and reduced-motion support.
- Domain, browser and AI-contract tests; deployment instructions.

Planning estimate: 3–5 hours for local implementation and validation, plus external deployment/configuration time. No production checkout, arbitrary code execution, live external CI runner or automatic deployment. The browser executes the bounded demo logic; Playwright independently exercises its UI. All external enterprise verification remains explicitly unproven.
